# Data license

The [MIT license](./LICENSE) covers only the **code** in this repository (the scripts in `scripts/` and the schema).

The **Bible texts** under `versions/` are not MIT. Each version keeps its own license, declared in its `metadata.json`:

| `license` | What it means for you |
|-----------|-----------------------|
| `public-domain` | No copyright. Use freely. |
| `cc0` | Dedicated to the public domain (CC0 1.0). Use freely. |
| `cc-by` | Creative Commons Attribution. Use freely, **with credit**: reproduce the `attribution` field. |
| `cc-by-sa` | Creative Commons Attribution-ShareAlike. Credit, and share derivatives under the same license. |
| `wlc-license` | Westminster Leningrad Codex terms: free to copy, distribute and modify, attribution requested. See https://tanach.us/. |

Versions with `"sourceVerified": false` have a public-domain claim that is not confirmed yet. See [SOURCES.md](./SOURCES.md#unverified-provenance) before redistributing them commercially.

Copyright terms vary by country. [SOURCES.md](./SOURCES.md) has the per-version provenance and jurisdictional notes.
